# Volume

Volume is stored on each candle and is not a term in either zone score.

The COCHINSHIP daily payload includes `volume` on every bar. The last bar in this session had volume 502702 and `source: "historical"`. V3 `formationDetails` candles can carry that field through with the OHLC.

`scoreComponents` on all 491 inspected V3 zones are compactness, role clarity, departure strength, close-break distance, prior structure, gap, and origin. Volume is not one of them. The V2 weight table is base count, compactness, departure, leg-out range, terminal body, achievement, freshness, and follow-through. Volume is not one of those either.

VWMA is available as a moving-average type, so volume can enter a plotted average when a user adds one. The saved chart had no indicators. No volume-spike, climax, or effort-versus-result rule was found.
